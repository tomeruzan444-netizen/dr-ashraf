# אתר ד״ר אשרף אטמנה - רפואת שיניים ואסתטיקה

אתר סטטי (HTML/CSS/JS טהור), ללא תלויות חיצוניות, ללא framework וללא שלב build חובה.
כל דף נטען כ-HTML מלא - כלומר מרונדר לחלוטין בצד השרת מבחינת מנועי חיפוש, וטוען מהר מאוד.

---

## ✅ מה צריך לעדכן לפני עלייה לאוויר

הרשימה הזו היא **חובה**. כל פריט מסומן בקוד בהערה `⚠️`.

| # | מה | איפה |
|---|-----|-------|
| 1 | **דומיין** - כרגע נעשה שימוש ב־`https://dr-atamna.co.il` כמציין מקום | חיפוש והחלפה של `dr-atamna.co.il` בכל הקבצים: `*.html`, `sitemap.xml`, `robots.txt` |
| 2 | **שעות פעילות** - כרגע א׳-ה׳ 09:00-19:00, ו׳ 09:00-13:00 (מציין מקום) | `index.html` (topbar, כרטיס שעות, footer, JSON-LD), `contact.html`, `about.html` |
| 3 | **כיתובי מקרי הלפני/אחרי** - נכתבו לפי מה שנראה בתמונות בלבד. כדאי לאשר או לתקן לשמות הטיפולים המדויקים | `index.html` (חפשו `ba__caption`), `_build/services.main.html` |
| 4 | **אישורי מטופלים** - לוודא שקיים אישור בכתב לפרסום כל תמונת לפני/אחרי | - |
| 5 | **נגישות המרפאה הפיזית** - לפרט לפי המצב בפועל | `accessibility.html`, סעיף 5 |
| 6 | **שם רכז/ת הנגישות** | `accessibility.html`, סעיף 6 |
| 7 | **מדיניות פרטיות** - מומלץ שעו״ד יעבור על הנוסח | `privacy.html` |
| 8 | **רשתות חברתיות** - אם יש פייסבוק/אינסטגרם, להוסיף קישורים ב־footer ולהוסיף `sameAs` ל־JSON-LD | `index.html` (footer + JSON-LD) |

### אופציונלי אך מומלץ
- **קואורדינטות מדויקות** - להוסיף `geo` (latitude/longitude) ל-JSON-LD בדף הבית ובדף צור קשר.
- **Google Business Profile** - לאמת את העסק ולחבר את אותה כתובת ואותו טלפון בדיוק כפי שמופיעים באתר (NAP עקבי = דירוג מקומי טוב יותר).
- **Google Search Console** - להגיש את `sitemap.xml` אחרי העלייה לאוויר.

## 🖼️ התמונות באתר

כל התמונות באתר הן **תמונות אמיתיות** של המרפאה, שעובדו אוטומטית לפורמט web:

| היכן | קובץ | מקור |
|------|-------|-------|
| **תמונת הנושא בדף הבית** | `assets/img/dr-asharaf-cutout-{480,720}.webp` | `תמונת תדמית דר אשרף.webp` - הרקע הוסר, נשארו רק ד״ר אשרף והחלוק הלבן |
| **סקשן אודות** (בית + עמוד אודות) | `assets/img/dr-asharaf-portrait.webp` | `תמונה של דר אשרף.webp`, חתוך ליחס 4:5 |
| **סקשן המרפאה** | `assets/img/clinic.webp` | `קליניקה.webp` |
| **גלריית לפני/אחרי** | `assets/img/results/case-NN-{before,after}.webp` | 11 המקרים מהתיקייה `תמונות לפני ואחרי` |
| **תמונת שיתוף ברשתות** | `assets/img/og-image.jpg` | לוגו + תמונת ד״ר אשרף על רקע המותג |

הקבצים המקוריים נשארו במקומם בתיקיות `assets/img/תמונות לפני ואחרי/` ו-`assets/img/תמונות של דר אשרף/`.
אפשר למחוק אותן מהעלאה לשרת - הן לא בשימוש באתר עצמו.

### הוספת מקרי לפני/אחרי חדשים

1. שמרו את התמונה החדשה בתיקייה `assets/img/תמונות לפני ואחרי/`
   (קובץ אחד שמכיל **לפני משמאל ואחרי מימין**, עם קו מפריד לבן - בדיוק כמו הקיימות),
   בשם שמכיל את מספר המקרה, למשל `מקרה 13 לפני ואחרי.png`.
2. הריצו:
   ```bash
   cd _build
   python process-images.py
   ```
   הסקריפט מזהה לבד את הקו המפריד, חותך לשניים, מיישר ליחס 4:5, מקטין וממיר ל-WebP.
3. הוסיפו כרטיס חדש ב-`index.html` (העתיקו בלוק `<figure class="ba">` קיים ושנו את המספר והכיתוב).

> דרישות לסקריפט: `pip install pillow numpy`

## 📬 טופס יצירת הקשר

כברירת מחדל הטופס **פותח את תוכנת הדוא״ל של המבקר** עם הפנייה ממולאת מראש
(`mailto:drasrf.clinic@gmail.com`). זה עובד בכל אחסון, גם סטטי, וללא שרת.

כדי לקבל את הפניות ישירות למייל בלי שהמבקר יצטרך תוכנת דוא״ל, הוסיפו endpoint
(למשל Formspree, Web3Forms, Netlify Forms או סקריפט משלכם) לתגית ה-`<form>`:

```html
<form class="form" data-contact data-endpoint="https://formspree.io/f/XXXXXXX" novalidate>
```

הסקריפט ישלח `POST` עם JSON בשדות: `name`, `phone`, `email`, `subject`, `message`.
בטופס כבר קיים שדה honeypot נסתר (`company`) לסינון בוטים.

## ⚡ ביצועים ופרטיות

- **אפס בקשות לצד שלישי** בטעינת העמוד - גופנים מאוחסנים מקומית, אין CDN, אין analytics, אין עוגיות מעקב.
- מפת Google נטענת **רק בלחיצה** על הכפתור (facade) - לא מכבידה על הטעינה ולא שולחת נתונים מראש.
- אייקונים כ-SVG sprite מוטמע - אין בקשות נוספות ואין font-icons.
- CSS יחיד (~50KB), JS יחיד (~10KB, `defer`), תמונות WebP עם `loading="lazy"` ומידות מפורשות (אין CLS).
- גופנים: 2 קבצים בלבד (~45KB סה״כ) עם `preload` ו-`font-display: swap`.
- דף הבית בטעינה ראשונה: **~220KB ב-8 בקשות**. 22 תמונות הגלריה נטענות רק בגלילה.

אם תוסיפו Google Analytics / Meta Pixel - **חובה** לעדכן את סעיף 5 ב-`privacy.html`
ולהוסיף באנר הסכמה לעוגיות.

## 🚀 העלאה לאוויר

אין שלב build. פשוט מעלים את כל תיקיית הפרויקט לשרת (למעט `_build/` ו-`brand/`, שהם פנימיים).
עובד על כל אחסון סטטי - Netlify, Vercel, Cloudflare Pages, GitHub Pages, cPanel רגיל.

**חשוב:** להגיש את האתר ב-HTTPS ולהגדיר את `404.html` כדף השגיאה של השרת.

תצוגה מקומית:

```bash
python -m http.server 8000
# ואז http://localhost:8000
```

## 🔧 עריכת התפריט / הפוטר בכל הדפים בבת אחת

הכותרת, התפריט הנייד, הפוטר וסט האייקונים משוכפלים בכל דף (כך אין בקשות רשת נוספות).
כדי לשנות אותם בכל הדפים בבת אחת:

1. ערכו את הבלוק הרלוונטי ב-`index.html` (הוא מקור האמת).
2. הריצו:

```bash
cd _build
python assemble.py services:services.html about:about.html contact:contact.html \
                   privacy:privacy.html accessibility:accessibility.html 404:404.html
```

הסקריפט לוקח את ה-chrome המשותף מ-`index.html`, מחבר אליו את ה-`head` וה-`main`
של כל עמוד מתוך `_build/`, ומעדכן את סימון העמוד הפעיל בתפריט (`aria-current`).

לעריכת **תוכן** של עמוד פנימי - ערכו את `_build/<page>.main.html` והריצו את הסקריפט,
או פשוט ערכו ישירות את קובץ ה-HTML הסופי (שתי הדרכים תקפות).
